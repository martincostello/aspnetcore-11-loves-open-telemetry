# Language logos

Language logos from [Simple Icons](https://simpleicons.org) 16.36.0 (CC0), filled with each brand's colour.
The OpenTelemetry logo (`opentelemetry.svg`) is the colour icon from the [CNCF artwork](https://github.com/cncf/artwork/tree/main/projects/opentelemetry)
repository, in OpenTelemetry's two brand colours. The logos remain trademarks of their respective owners.
